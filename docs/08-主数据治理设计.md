# 08-主数据治理设计

## 1. 定位

主数据治理是消费方项目职责。Synapse Framework 只提供主数据治理所需的技术支撑和规范。

## 2. 框架可提供能力

- 编码规则抽象。
- 字典参数抽象。
- 元数据字段描述。
- 审计字段规范。
- 数据版本和乐观锁规范。
- 数据变更事件抽象。

## 3. 框架不提供能力

- 客户、供应商、物料、组织等主数据模型。
- 主数据维护页面。
- 主数据审批流程。
- 主数据导入导出业务。

## 4. 治理规则

- 所有主数据业务表由消费方拥有。
- 框架可以提供字段命名、审计字段、逻辑删除、乐观锁规则。
- 主数据变更需要可审计、可追踪、可补偿。
