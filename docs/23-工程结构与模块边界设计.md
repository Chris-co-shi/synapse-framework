# 23-工程结构与模块边界设计

## 1. 包结构

```text
com.indigo.synapse.<module>
├── autoconfigure
├── properties
├── core
├── context
├── annotation
├── port
├── adapter
├── propagation
├── resilience
├── infrastructure
└── support
```

## 2. 包职责

- `autoconfigure`：自动配置。
- `properties`：配置属性。
- `core`：核心抽象。
- `context`：上下文。
- `annotation`：技术注解。
- `port`：SPI / Port。
- `adapter`：外部适配。
- `propagation`：上下文传播。
- `resilience`：熔断、重试、降级。
- `infrastructure`：内部技术实现。
- `support`：测试或轻量辅助。

## 3. 注释规则

- 公共 SPI、Port、Annotation、AutoConfiguration、Properties 必须有 Javadoc。
- 并发、幂等、限流、熔断、上下文传播必须有必要短注释。
- 注释解释原因、边界和风险。
- 禁止机械注释。

## 4. 禁止结构

- `controller` 中出现业务 Controller。
- `entity` 中出现业务 Entity。
- `application` 中出现业务用例。
- `admin-ui` 或 frontend 目录。
- `*Application` 生产启动类。
