# 14-数据库模型设计

## 1. 定位

本仓库不交付业务数据库模型。本文档规定框架内部技术表和消费方数据库规范。

## 2. 技术表命名

如框架确需技术表，使用：

```text
synapse_audit_event
synapse_task_execution
synapse_file_object
synapse_message_outbox
```

禁止：

```text
iam_*
sys_*
biz_*
```

## 3. 基础字段

```sql
id varchar(19) PRIMARY KEY,
tenant_id varchar(19) NULL,
created_at TIMESTAMP NOT NULL,
created_by varchar(19) NULL,
updated_at TIMESTAMP NOT NULL,
updated_by varchar(19) NULL,
deleted SMALLINT NOT NULL DEFAULT 0,
version INTEGER NOT NULL DEFAULT 0
```

## 4. 持久化边界

- Entity 只在 `infrastructure.persistence.entity`。
- Mapper 只在 `infrastructure.persistence.mapper`。
- Repository Adapter 只在 `infrastructure.persistence.repository`。
- Entity 不得暴露给 Controller 或前端。

## 5. Migration 规则

- 所有 DDL 走 Flyway。
- migration 合入后不得修改。
- 修复用新 migration。
- 生产禁止 clean。
