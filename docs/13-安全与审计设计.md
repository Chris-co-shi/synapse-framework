# 13-安全与审计设计

## 1. 安全边界

Synapse Security 提供 OAuth2、JWT、JWK、资源服务器保护、Principal、权限判断 SPI。

不提供：

- 登录业务。
- 用户管理。
- 角色菜单。
- 注册和找回密码。

## 2. 审计边界

Synapse Audit 提供：

- AuditEvent。
- AuditPublisher。
- AuditRepository Port。
- 审计注解和拦截扩展点。

不提供业务日志查询页面。

## 3. 默认规则

- 默认拒绝。
- 公开端点显式白名单。
- Token 明文不得日志输出。
- 生产环境禁止默认密钥。
- 审计事件必须带 traceId。

## 4. 注释要求

安全和审计相关公共 API 必须说明误用风险、敏感字段和默认行为。
