# 25-开发前技术决策记录

## 1. 不 Fork 开源框架

决策：不 Fork。

原因：

- 历史包袱重。
- 技术栈不可控。
- 许可证和代码来源风险更高。

## 2. 不做启动应用

决策：framework 仓库不提供生产启动类。

测试中的 `TestApplication` 只允许用于测试上下文。

## 3. 不做业务模块

决策：用户、角色、菜单、组织、订单、工单等业务模型不进入本仓库。

## 4. MyBatis-Plus 使用

决策：使用 MyBatis-Plus，但限制在持久化实现边界内。

## 5. 微服务支持

决策：提供 cloud 基础抽象和 adapter，不提供业务微服务应用。

## 6. 注释策略

决策：公共契约和复杂边界必须注释，简单代码不做机械注释。
