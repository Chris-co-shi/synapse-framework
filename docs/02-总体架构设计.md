# 02-总体架构设计

## 1. 架构总览

```text
synapse-framework
├── synapse-bom
├── synapse-core
├── synapse-web
├── synapse-data
├── synapse-cache
├── synapse-security
├── synapse-audit
├── synapse-tenant
├── synapse-data-permission
├── synapse-message
├── synapse-file
├── synapse-task
├── synapse-cloud
└── synapse-starter
```

## 2. 模块分层

```text
Starter Layer
  -> synapse-starter

Foundation Layer
  -> common / web / data / cache / security / audit

Extension Layer
  -> tenant / data-permission / message / file / task / cloud

Adapter Layer
  -> Redis / RocketMQ / MinIO / OSS / Seata / Nacos / OpenFeign / Gateway / Resilience4j
```

## 3. 依赖方向

允许：

```text
starter -> foundation + extension
extension -> foundation
adapter -> port
web/data/cache/security/audit -> common
cloud -> common/web/security/tenant
```

禁止：

```text
common -> web/data/security/cache
framework -> business application
framework -> startup application
framework -> Admin UI
technical module -> business module
```

## 4. 设计原则

- 技术能力模块化。
- 外部组件 adapter 化。
- 业务语义消费方拥有。
- 默认配置可覆盖。
- 自动配置可关闭。
- 公共契约稳定演进。
