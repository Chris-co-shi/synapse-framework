# 02-总体架构设计

## 1. 架构总览

```text
synapse-framework
├── synapse-bom
├── synapse-core
├── synapse-web
├── synapse-data
├── synapse-cache
├── synapse-security
├── synapse-oauth2
├── synapse-audit
├── synapse-message
└── synapse-file
```

## 2. 模块分层

```text
Foundation Layer
  -> core / web / data / cache / security / oauth2 / audit

Extension Layer
  -> message / file

Adapter Layer
  -> Redis / RocketMQ / MinIO / OSS
```

## 3. 依赖方向

允许：

```text
extension -> foundation
adapter -> port
web/data/cache/security/oauth2/audit -> core
```

禁止：

```text
common -> web/data/security/cache
framework -> business application
framework -> startup application
framework -> Admin UI
technical module -> business module
```

## 4. 设计原则

- 技术能力模块化。
- 外部组件 adapter 化。
- 业务语义消费方拥有。
- 默认配置可覆盖。
- 自动配置可关闭。
- 公共契约稳定演进。
