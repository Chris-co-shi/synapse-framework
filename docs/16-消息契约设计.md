# 16-消息契约设计

## 1. 消息 Envelope

```text
MessageEnvelope<T>
  messageId
  topic
  tag
  key
  headers
  payload
  traceId
  tenantId
  createdAt
```

## 2. Header 规范

推荐技术 header：

- `x-trace-id`
- `x-tenant-id`
- `x-message-id`
- `x-idempotency-key`
- `x-source-service`

## 3. 契约规则

- payload 由消费方定义。
- topic 由消费方定义。
- 框架只定义传输外壳和技术 header。
- 版本变化必须向后兼容或显式声明 breaking change。

## 4. 禁止事项

- 内置业务 Topic。
- 内置业务消息体。
- 消费失败只打印日志不处理。
