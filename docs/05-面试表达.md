# 05-面试表达

## 1. 一句话表达

Synapse Framework 是一个 Java 企业应用技术底座，负责沉淀通用基础设施能力，不承载业务系统。

## 2. 架构表达

它通过 BOM、auto-configuration、SPI、Port 和轻量 adapter 的方式，把 Core、Web、Data、Cache、Security、OAuth2、Audit、Message、File 等一阶段能力模块化，供业务项目按需集成。

## 3. 边界表达

本仓库不做用户、角色、菜单、订单等业务模型，也不提供启动应用。业务项目只依赖框架，框架永远不反向依赖业务项目。

## 4. 技术亮点

- 自动配置可插拔。
- 外部组件 adapter 化。
- 安全上下文、权限抽象、审计、Trace 上下文统一传播。
- Redis Lua 实现锁、限流、幂等。
- OAuth2/JWT/JWK 技术抽象独立归属 `synapse-oauth2`，不与业务登录系统绑定。
- 文档和 Skill 约束 AI Agent 长期协作。

## 5. 风险控制表达

框架最容易失控的地方是业务语义混入基础模块。因此所有模块必须通过文档、包结构、测试和 Skill 固定边界。
