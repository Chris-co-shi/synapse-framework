# 07-租户组织与权限模型

## 1. 定位

本仓库只提供租户、组织、权限相关技术抽象，不实现租户管理、组织管理、用户角色菜单等业务。

## 2. 租户抽象

允许提供：

- TenantContext。
- TenantResolver。
- TenantAware。
- TenantIgnore。
- Tenant propagation。

禁止：

- 租户表。
- 租户套餐。
- 租户账单。
- 租户后台页面。

## 3. 权限抽象

允许提供：

- Principal 抽象。
- PermissionEvaluator SPI。
- `@RequirePermission` 注解。
- 方法级授权集成点。

禁止：

- 用户表。
- 角色表。
- 菜单表。
- 业务权限码。

## 4. 组织抽象

组织、部门、岗位属于消费方业务模型。框架只允许保留数据权限所需的组织范围抽象，不持有组织树数据。

## 5. 数据权限关系

```text
Consumer Principal
  -> DataScope Provider SPI
  -> Synapse Data Permission Rule
  -> Query Adapter
```

框架禁止支持任意 SQL 片段拼接。
