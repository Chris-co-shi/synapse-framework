# 19-字典参数与编码规则设计

## 1. 定位

字典、参数、编码规则在框架中只作为技术抽象，不作为业务管理模块。

## 2. 可提供抽象

- DictionaryProvider。
- ParameterProvider。
- CodeGenerator Port。
- CodeRule。

## 3. 禁止事项

- 字典管理页面。
- 参数配置页面。
- 系统参数业务表。
- 固定业务编码规则。

## 4. 编码规则建议

消费方编码规则应明确：

- 前缀。
- 日期段。
- 序列号。
- 租户隔离。
- 并发安全。

框架可以提供序列生成和锁能力，但不决定业务编码格式。
