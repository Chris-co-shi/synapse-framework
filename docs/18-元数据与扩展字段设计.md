# 18-元数据与扩展字段设计

## 1. 定位

元数据与扩展字段用于描述技术模型和消费方可扩展点，不用于在框架中实现低代码平台。

## 2. 可提供能力

- FieldDescriptor。
- TypeDescriptor。
- ExtensionFieldDefinition。
- ValidationRuleDescriptor。
- DisplayHint。

## 3. 禁止事项

- 在线表单运行时。
- 业务页面设计器。
- 固定业务字段。
- 框架直接修改消费方表结构。

## 4. 使用边界

元数据可以用于生成文档、校验配置、adapter 映射和测试支撑。业务字段定义由消费方维护。
