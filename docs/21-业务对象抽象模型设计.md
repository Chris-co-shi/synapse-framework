# 21-业务对象抽象模型设计

## 1. 定位

框架不实现具体业务对象，但可以提供业务对象的技术抽象，帮助消费方统一建模。

## 2. 可提供抽象

- BusinessObjectRef。
- ObjectIdentity。
- ObjectType。
- ObjectMetadata。
- ObjectEvent。

## 3. 禁止事项

- 具体业务对象类。
- 业务对象表。
- 业务对象 Controller。
- 业务对象页面。

## 4. 使用场景

- 审计事件关联业务对象。
- 文件附件关联业务对象。
- 消息事件关联业务对象。
- 任务执行关联业务对象。

框架只保存引用，不理解业务对象内部含义。
