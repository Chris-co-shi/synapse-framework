# 09-消息与补偿机制设计

## 1. 定位

Synapse Message 提供消息基础设施抽象，不定义业务 Topic 和业务消息体。

## 2. 消息抽象

```text
MessageEnvelope
  -> messageId
  -> topic
  -> tag
  -> key
  -> headers
  -> payload
  -> traceId
  -> tenantId
```

## 3. 补偿机制

允许提供：

- Outbox Port。
- Retry Policy。
- Dead Letter Port。
- Compensation Task Port。
- Message Idempotency。

禁止：

- 内置业务补偿流程。
- 固定业务 Topic。
- 直接吞掉发送失败。

## 4. 测试要求

- 消息序列化失败。
- 重复消费。
- 发送失败重试。
- 死信处理。
- Trace / Tenant 上下文传播。
