# 03-核心链路设计

## 1. Web 请求链路

```text
Consumer HTTP Request
  -> Synapse Trace Filter
  -> Synapse Security Filter
  -> Consumer Controller
  -> Synapse Response / Exception Handler
  -> Consumer HTTP Response
```

Synapse 只提供 Trace、校验、异常和响应规范，不提供业务 Controller。

## 2. Data 访问链路

```text
Consumer Repository Adapter
  -> MyBatis-Plus Mapper
  -> Synapse Data Plugins
  -> Datasource / Dialect
  -> Database
```

Synapse 只提供配置、插件、方言、多数据源和迁移规范，不提供业务表。

## 3. Cache 并发链路

```text
Consumer Use Case
  -> Idempotency / Lock / RateLimit
  -> Redis Script Executor
  -> Redis
```

幂等键、锁粒度、限流维度由消费方决定。

## 4. Security 链路

```text
Request
  -> Resource Server
  -> JWT / JWK Validation
  -> Principal Resolver
  -> Permission Evaluator SPI
```

用户、角色、权限数据来源由消费方提供。

## 5. Cloud 远程调用链路

```text
Consumer Service
  -> Remote Call Port
  -> Context Propagation
  -> LoadBalancer
  -> Resilience Policy
  -> OpenFeign / WebClient Adapter
  -> Remote Service
```

框架不固定业务服务名、网关路由或业务 Feign Client。

## 6. Audit 链路

```text
Technical Event
  -> Audit Event Builder
  -> Audit Publisher
  -> Audit Repository Port
  -> Consumer Adapter
```

框架定义审计事件结构和发布机制，审计落库方式由消费方决定。
